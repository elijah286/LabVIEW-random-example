 IIR filter specifications

IIR filter specifications is the cluster containing design parameters for an IIR filter.

    		Topology

    Topology determines the design type of the filter.

    		Type

    Type specifies the passband of the filter according to the following values.

    		Order

    Order is the filter order.

    		Lower Fc

    Lower Fc is the low cutoff frequency and must observe the Nyquist criterion.

    		Upper Fc

    Upper Fc is the high cutoff frequency. This parameter is ignored when Type is 0 (lowpass) or 1 (highpass).

    		PB Ripple

    PB Ripple must be greater than zero, and you must express it in decibels. If PB Ripple is less than or equal to zero, the VI sets the signal out waveform to be empty and returns an error. The default is 1.0.

    		SB Attenuation

    SB Attenuation specifies the stopband attenuation. SB Attenuation must be greater than zero and expressed in decibels. If SB Attenuation is less than or equal to zero, the VI sets the signal output to zero or an empty array and returns an error. The default is 60.0.

Analog Physical Channel 2

Physical Channel(s) specifies the names of the physical channels to use to create virtual channels. The DAQmx physical channel constant lists all physical channels on devices and modules installed in the system.

To specify a range of physical channels, use a colon between two channel numbers or two physical channel names:

Dev1/ai0:4

Dev1/ai0:Dev1/ai4

You can specify channel ranges in reverse order:

Dev1/ai4:0

Use commas to separate physical channel names and ranges in a list as follows:

Dev1/ai0, Dev1/ai3:6

Counter

Counter specifies the names of the counter resource to use for the task.

Sample Rate

Sample Rate specifies the sampling rate in samples per channel per second. If you use an external source for the Sample Clock, set this input to the maximum expected rate of that clock.

Number of Samples

Samples per Loop specifies the number of samples to read per loop iteration.

For example, if the sample rate is 100 Hz, and Samples per Loop is 100, the loop will execute once per second.
