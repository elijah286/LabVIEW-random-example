Get Terminal Name with Device Prefix.vi

This example takes in a DAQmx Task and a terminal and converts this to a terminal which includes the device prefix specified in the DAQmx Physical Channel Control.

For example:

DAQmx Task/channels in=Dev1/ai1:2

Terminal=ai/StartTrigger

Device+Terminal=/Dev1/ai/StartTrigger
